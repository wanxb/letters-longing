# 待采集书信语料计划

## 目标

在现有 1200 条发布短句和 2200+ 候选短句基础上，继续扩展“传统书信开头、结尾、正文表达、公开信件”的语料库。

下一阶段目标：

- 发布短句总量：3000 条
- 候选池总量：6000 条以上
- 中文占比：不少于 65%
- 开头短语：不少于 400 条
- 结尾短语：不少于 300 条
- 每条短句必须保留 `sourceId`、来源 URL、语言、类型、标签和质量分

## 优先补齐方向

### 1. 结尾短语库

现状：发布数据中结尾短语约 60 条，偏少。

优先采集：

- 中文尺牍课本中的“敬请”“顺颂”“即颂”“专此敬请”等结尾格式
- 民国尺牍范本中的署名前套语
- 英文公版 letter-writer 手册中的 complimentary close
- 真实书信里的自然结尾，如 `Yours sincerely`、`Ever yours`、`Your affectionate friend`

目标：新增 250 条以上可用结尾短语。

### 2. 中文传统尺牍

优先来源：

- 维基文库《儿童新尺牍》
- 维基文库《通俗新尺牍》相关索引页，如可获取 OCR 文本则纳入
- 维基文库“尺牍”“书信”“书”分类下的古代书札
- 古文中题名含“书”“与某书”“答某书”“上某书”的公版文本

目标：新增 1200 条中文候选，发布 700 条。

重点标签：

- 亲情
- 友情
- 公开信
- 训诫
- 问候
- 敬意
- 请托
- 致歉

### 3. 中文公开信与陈情书

优先来源：

- 李白《与韩荆州书》
- 白居易《与元九书》
- 司马迁《报任安书》
- 李斯《谏逐客书》
- 韩愈《与孟尚书书》《答李翊书》等
- 梁启超公开书信、介绍书、上书类文本

目标：新增 800 条候选，发布 400 条。

注意：

- 这类文本更接近公开陈情，不完全等同私人信件。
- 入库时 `relationTags` 优先标为 `公开信`、`训诫`、`友情`。
- `usageScene` 要说明适合“立场说明、荐举、请托、陈情”。

### 4. 家书与亲情表达

### 5. 英文书信与 letter-writing 手册

优先来源：

- Project Gutenberg: `How to Write Letters`
- Project Gutenberg: `The New Century Standard Letter-Writer`
- Project Gutenberg: `Putnam's Phrase Book`
- Project Gutenberg: Browning-Barrett letters
- English Wikisource: Jane Austen letters
- English Wikisource: Lincoln letters
- English Wikisource: Oscar Wilde letters

目标：新增 1200 条候选，发布 600 条。

重点提取：

- `Dear ...`
- `My dear ...`
- `I received your letter`
- `I am writing to ...`
- `Yours sincerely`
- `Yours faithfully`
- `Your affectionate friend`
- 慰问、感谢、歉意、思念类正文句

## 脚本任务

### T1 扩展 source manifest

在 `scripts/collect-letter-corpus.ts` 中新增来源：

- `source-018` 起继续编号
- 每个来源必须写明 `licenseNote`
- 不确定版权的来源只输出候选，不合并发布

### T2 优化中文尺牍抽取

当前《儿童新尺牍》存在竖排模板、跨行问安、注解混入问题。

需要增强：

- 专门识别 `{{VtextStart}}...{{VtextEnd}}`
- 将跨行的 `专此敬请` + `福安` 合并为一条
- 丢弃以 `㊀`、`注解`、`作...讲`、`意思` 开头或结尾的解释句
- 将 `某某叩上`、`某月某日` 识别为署名结构，不作为正文短句

### T3 结尾短语增强

新增规则：

- 中文结尾：
  - `敬请...安`
  - `顺颂...祺`
  - `即颂...祉`
  - `专此敬请...安`
  - `肃此敬请...安`
  - `伏乞...`
- 英文结尾：
  - `Yours truly`
  - `Yours sincerely`
  - `Yours faithfully`
  - `Respectfully yours`
  - `Cordially yours`
  - `Affectionately yours`
  - `Your obedient servant`

目标：下一轮发布数据中 closing 不少于 300 条。

### T4 质量抽检

每轮合并后抽检：

- 开头 30 条
- 结尾 30 条
- 正文 50 条
- 中文 50 条
- 英文 50 条

抽检重点：

- 是否混入目录、注解、脚注、版权页
- 是否过短或无实际书信用途
- 类型是否误判
- 语气标签是否大体合理

## 验收标准

每一批采集完成后必须通过：

```bash
npm run validate:data
npm run build:search
npm run build:sitemap
npm run check:links
npm run typecheck
```

统计指标必须输出：

- 发布短句总数
- 候选短句总数
- 中文/英文数量
- opening/closing/body 数量
- 每个 sourceId 的贡献数量
- 低质量过滤数量
