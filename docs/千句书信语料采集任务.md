# 千句书信语料采集任务

## 目标

为“尺素”项目补充至少 1000 条可检索、可溯源的书信短句，重点覆盖传统写信的开头、结尾、问候、致歉、慰问、诀别、劝诫、思念、感谢、立场说明等表达。

中文为主，英文为辅。第一阶段目标比例：

- 中文：不少于 700 条
- 英文：不少于 300 条
- 开头短语：不少于 120 条
- 结尾短语：不少于 120 条
- 正文可用短句：不少于 760 条

## 数据落点

- `data/sources.json`：来源元信息和版权说明
- `data/letters.json`：公开信件或书信集合中的代表性信件
- `data/excerpts.json`：最终发布的短句
- `data/topics.json`：面向站内浏览的专题聚合
- `public/search-index.json`：由脚本生成，不手写

批量采集的中间结果可以先放入：

- `data/generated/excerpt-candidates.json`
- `data/generated/source-manifest.json`

候选池通过质量筛选后再合并进 `data/excerpts.json`。

## 来源优先级

### A 级：优先批量采集

这些来源版权状态清晰、文本公开、适合大量抽句。

- 维基文库：曾国藩家书
- 维基文库：传统“书”类文章与公开信分类
- 维基文库：林觉民《与妻书》《禀父书》
- 维基文库：诸葛亮《诫子书》《又诫子书》及相关书信
- 维基文库：白居易《与元九书》
- 维基文库：梁启超书信与公开书
- Project Gutenberg：Robert Browning 与 Elizabeth Barrett Barrett 书信
- 英文 Wikisource：Jane Austen letters
- 英文 Wikisource：Abraham Lincoln letters
- 英文 Wikisource / Project Gutenberg：Oscar Wilde public-domain letters

### B 级：候选采集

这些来源可以作为扩展，但入库前要更严格检查版权、文本版本和上下文。

- 鲁迅《两地书》：部分地区公版，但美国版权状态复杂，默认只做候选，不直接发布全文
- 梁启超、康有为、孙中山相关公开信：优先短句摘录，不直接整封搬运
- 古代奏疏、表文、书札：可用于“公开信/陈情/荐书”类表达，但要标记语境

## 任务拆解

### T1 来源清单

产出：`data/generated/source-manifest.json`

要求：

- 每个来源包含 `id`、`title`、`author`、`url`、`language`、`copyrightStatus`
- 标注是否允许全文入库：`allowFullText`
- 标注默认关系标签：如 `亲情`、`友情`、`爱情`、`慰问`、`训诫`、`公开信`

### T2 批量抓取脚本

产出：`scripts/collect-letter-corpus.ts`

要求：

- 支持 Wikisource 页面 raw 文本抓取
- 支持 Project Gutenberg UTF-8 文本抓取
- 保留来源 URL 和 source id
- 网络失败时跳过并报告，不中断全任务
- 输出候选短句到 `data/generated/excerpt-candidates.json`

### T3 文本清洗与切句

规则：

- 去除目录、导航、注释、模板、页脚
- 中文按 `。！？；：` 和换行切分，保留适合书信的短句
- 英文按句号、问号、叹号和常见书信结尾切分
- 单条长度建议：中文 4-80 字，英文 3-35 词
- 去重：按规范化文本去重

### T4 类型识别

候选短句的 `type`：

- `opening`：称谓、问候、如晤、Dear、My dear 等
- `closing`：敬禀、谨启、yours、faithfully、affectionate friend 等
- `body`：正文表达

### T5 标签与质量分

每条候选至少包含：

- `relationTags`
- `emotionTags`
- `usageScene`
- `qualityScore`

质量门槛：

- 直接发布：`qualityScore >= 75`
- 候选保留：`60 <= qualityScore < 75`
- 丢弃：`qualityScore < 60`

### T6 合并入库

产出：

- `data/excerpts.json` 至少 1000 条
- `data/sources.json` 补足所有来源
- `data/letters.json` 补充代表性公开信
- `data/topics.json` 补充专题索引

合并后必须通过：

```bash
npm run validate:data
npm run build:search
npm run check:links
npm run typecheck
```

## 第一批里程碑

### M1：300 条

来源：

- 曾国藩家书 1-3
- 与妻书、禀父书
- 诫子书、与元九书
- Browning-Barrett letters

目标：验证采集脚本、字段结构、搜索索引。

### M2：1000 条

新增来源：

- 曾国藩家书更多章节
- Wikisource 书信分类
- Jane Austen letters
- Lincoln letters
- Wilde letters
- 梁启超公开书信

目标：站内开头、结尾、正文短句达到可用规模。

### M3：3000 条

新增来源：

- 更多古代“书”“启”“札”“公开信”
- 更多英文公版书信集
- 人工精选高质量开头/结尾模板

目标：形成可持续扩展的书信语料库。
